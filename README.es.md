## Qué incluye

Una guía en portugués, cinco figuras originales con créditos, una comparación interactiva de Lasso y una actividad de comprensión. El plan describe ocho sesiones y un laboratorio futuro; este repositorio no implementa Dream-RSI de forma científica.

## Ejecución local

```bash
python3 -m http.server 8765
# Abre http://localhost:8765/guia/es/
```

El HTML, CSS y JavaScript están incluidos; no se necesita compilación, cuenta ni API. Google Fonts es opcional y tiene fuentes de reserva locales. Las imágenes están en `guia/assets/`.
