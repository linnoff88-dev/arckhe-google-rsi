## What’s included

A Portuguese-language guide, five original figures with credits, an interactive Lasso comparison, and a comprehension activity. The plan describes eight sessions and a future lab; this repository does not implement Dream-RSI scientifically.

## Run locally

```bash
python3 -m http.server 8765
# Open http://localhost:8765/guia/en/
```

HTML, CSS, and JavaScript are inline; there is no build step, account, or API. Google Fonts are optional and have local fallbacks. Images are in `guia/assets/`.
